🔌 API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Autenticación:
  POST   /api/login           - Iniciar sesión
  POST   /api/logout          - Cerrar sesión
  GET    /api/me              - Usuario actual

Recursos (requieren auth):
  GET    /api/clientes        - Listar clientes
  GET    /api/equipos         - Listar equipos
  GET    /api/reparaciones    - Listar reparaciones
  GET    /api/facturas        - Listar facturas

Público:
  GET    /api/public/status/{codigo} - Consultar estado

1. Login:
   POST http://localhost:8000/api/login
   Body: {
     "email": "martinez@martinezservice.com",
     "password": "password"
   }
   Response: {
     "token": "..."
   }

2. Listar Reparaciones:
   GET http://localhost:8000/api/reparaciones
   Headers: {
     "Authorization": "Bearer {token}"
   }
